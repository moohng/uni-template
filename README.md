# Uni Template

A professional Uni-app scaffold for rapid development.

## Tech Stack
- **Framework**: Uni-app (Vue 3)
- **Language**: TypeScript
- **Styling**: UnoCSS + unocss-preset-weapp
- **Icons**: Lucide (via Iconify/UnoCSS)
- **State**: Pinia + Persistence

## Directory Structure
- `docs/`: Design assets, requirements, and promotional materials.
- `src/`: Application source code.
  - `commons/`: API and utility functions.
  - `components/`: Global reusable components.
  - `pages/`: Page components.
  - `store/`: Pinia state management.
  - `static/`: Static assets (images, etc.).

## Getting Started
1. Install dependencies: `pnpm install`
2. Run development: `pnpm dev:mp-weixin`
3. Build production: `pnpm build:mp-weixin`
